# PixelPets · 掌心伙伴

一个可以慢慢玩的像素陪伴小游戏。认识 3 位伙伴，陪它们长成日光或月色形态，去集市和月灯小径带回故事，收集 8 件旅途纪念物。

## 开始游戏

1. 将整个压缩包解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 `开始游玩.cmd`。浏览器会打开 http://127.0.0.1:9783/ 。第一次加载需要几秒。
3. 选择伙伴、输入名字，点击“带它回家”。右上角可以切换中文 / English。

此 Windows x64 便携包已包含 Node.js 24 和编译好的游戏，无需安装 Godot、npm 或额外下载资源。游戏与服务都在本机运行，普通游玩不需要网络或钱包。如果端口被其他程序占用，启动器会显示提示；不要同时从多个解压目录启动。

## 怎么玩

- **陪伴**：喂食、玩耍、休息和小小出游会留下成长印记。每次有效照顾后等待 12 秒，界面会显示倒计时。6 次有效照顾后成长；日光 / 月色印记更多的一方决定形态，平局按伙伴自己的偏好决定。
- **寻找微光**：选择日光草地或月色小径，收集 6 束闪烁微光。可以点击、触屏轻点，或按 Enter / Space。没有倒计时惩罚，完成后提交一次真实照顾记录。
- **旅行**：选择目的地和行囊，点击出发。当前为明确标注的 45 秒加速旅程。伙伴回来后点击“揭晓明信片”。点心盒与小提灯影响故事；不会改变奖励概率。
- **卡册**：查看 8 件纪念物、成长形态和最近 50 次旅程中的已揭晓明信片。点击旧明信片可以再次阅读。尚未开放的图鉴条目只是设计预览。
- **日记**：服务保存实际发生的陪伴与旅行记录。新记录支持中英双语，旧版记录保留原文。
- **每日补给**：每天 UTC 00:00 补满 3 份（北京时间 08:00），每次旅行消耗 1 份。补给用完后仍可以照顾伙伴、玩微光小游戏、翻看回忆。没有死亡机制，也不用担心漏玩一天。

## 存档与退出

普通游玩的浏览器通行证保存在当前浏览器的站点存储里，伙伴数据在游戏文件夹的 `runtime/pets.sqlite` 中。继续使用同一解压目录、同一浏览器和 `127.0.0.1:9783` 地址即可接着玩。请保留整个游戏文件夹，不要删除 `runtime` 或清除浏览器站点数据。`localhost` 与 `127.0.0.1` 属于不同的浏览器存档来源。

退出时关闭游戏页面，并双击 `停止游戏.cmd`。如需备份，先停止游戏，再复制整个游戏文件夹；浏览器通行证不会随文件夹复制到另一台电脑。可选钱包恢复需要部署方配置并开放链上服务。

## 可选功能与版本范围

这份便携版完成了免费养成、小游戏、旅行、相册、收藏和本地存档。钱包、链上领取、旅程收据和赠送为独立的可选功能；便携包未配置链上部署，因此这些入口会说明尚未开放。旅途纪念物是游戏内记录，没有现金价值。无需进行任何交易就可以完整体验免费玩法。

`dist/windows/PixelPets.exe` 提供原生客户端：先启动本地服务，再运行它。原生客户端与浏览器使用各自的本机通行证，默认会进入不同档案；建议固定使用一种客户端。
