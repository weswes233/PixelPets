# 掌心伙伴 / PixelPets 实现状态

更新：2026-10-08（北京时间）。最终目标仍为完整像素宠物产品、公开服务及主网资产与交易；当前尚未达到完整发布标准。

## 可玩的客户端

- Godot 4.5.2，原创代码绘制三种像素宠物，以及各自的日光、月色成长形态。
- 免费领养、取名、喂食、陪玩、休息、出游收集记忆、成长分支、卡册和实际互动日记。
- 服务端保存档案、冷却时间与幂等事件；刷新或重启服务不会重新奖励同一事件。
- Web 和 Windows 导出。网页版支持钱包桥接；Windows 原生钱包配对尚未实现。
- 窄屏与横屏布局；出游环境与宠物当前成长形态分开显示，未进化的伙伴不会提前变成进化形态。
- 交换页可接收已核验的链上报价、精确 SOL 金额、交换目标和分页结果；浏览报价不会把别人的宠物加入自己的收藏。目前游戏内成交操作尚未开放。
- 日常游玩入口为 `http://127.0.0.1:9783/`，默认链服务关闭，真实玩家存档仍在 `runtime/pets.sqlite`。

## 已完成的链上基础与服务串联

- Anchor 程序：版本发行上限、唯一领取回执、共同签名领取、所有者与发行方共同签名的成长登记、托管交换、固定价买卖、撤销及暂停期间取回。
- 实际 Core 资产与集合；官方身份核对包括程序、集合、记录 PDA、所有者和插件规则。
- SDK：明确网络与完整 genesis 校验、精确整数金额、指令重建、共同签名验证、交易模拟、最终确认核对；只准备与读取，不自动广播。
- HTTP 服务：真实 SIWS / Ed25519 验签、钱包会话、持久化领取/成长请求、签名交易保存、过期重试、重启恢复及最终状态核对。
- 跨进程请求有 SQLite 租约和写入校验，被新请求接管的旧操作不能覆盖新结果。RPC 读请求与响应正文均有超时限制。
- 网页核对所选宠物、资产、接收人、发行方、网络、允许的单笔指令与共同签名，然后展示预计总支出并请钱包签名。
- 签名交易先保存恢复凭据再提交。提交不确定时核对原交易，恢复不要求签出另一笔交易。旧尝试后来被确认成功时，响应指向实际成功的资产和签名。
- 市场读取采用 finalized 状态及链上 Clock；批量核对托管所有权、挂单 PDA、成长记录、报价快照和有效期。查询失败明确报错，不伪装成空市场。

真实链测试运行 PixelPets SBF 与 Metaplex Core CPI，读取实际资产和最终确认。使用隔离本地链和无价值的测试资金，未提交公共链交易。服务测试采用脚本实现的 Wallet Standard 测试签名器，因此不等同于浏览器钱包扩展弹窗已经验收。

合约验收包含初始化权限、防重复领取、发行上限、不可逆成长分支、实际托管所有权、双向交换、后续指令失败时一起回滚、付款不足时前序付款回滚、手续费向下取整、挂单手续费快照、暂停时撤销和旧挂单编号不可重用。

Windows 节点的运行边界与复现命令见 [本地链验收说明](local-chain-testing.md)。官方兼容版本能完成即时验收，但首次自动快照需要当前环境没有的符号链接权限，不能当作长期运行的开发节点。测试完成后按进程路径与账本路径核验再停止，旧账本与失败证据保留。

## 完整发布仍待完成

1. 在游戏中完成上架、购买、交换、赠送，以及成交后档案所有权同步。合约能力已验证，完整玩家操作流程仍需完成。
2. 真实浏览器钱包扩展、两钱包操作、移动钱包浏览器与拒签/切换账号验收。
3. 钱包跨设备恢复、游客迁移与档案恢复。当前钱包已绑定其他游客时不会静默合并。
4. 原创像素素材与元数据的正式发布、内容地址和可用性核对；本地链的 metadata URI 是测试夹具，不能视为公开资产内容。
5. 公共测试网部署、公开 HTTPS、生产存储与备份、负载和运行维护。
6. 主网部署参数、费用、权限及发布验收。尚无主网资产发行或主网交易成功的结论。
7. AI 表达与只读硬件展示仍为后续扩展，当前不宣称冷钱包、硬件或通行证集成完成。

免费照顾与陪伴是基础体验。收费和玩家交易应服务于收藏、审美、表达和交换需求；当前没有付费抽卡、收益承诺、回购承诺或代币补贴。测试资金流不能证明真实付费需求成立，仍需要用户试玩与消费验证。
