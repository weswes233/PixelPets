# PixelPets 首轮界面与功能完善 · 2026-10-11

## 本轮改动

- 保留原创像素伙伴和奶油色风格，统一圆角卡片、导航选中态、文字对比度与状态栏。
- 页面宽度限制为 1040 像素，桌面窗口使用实际可用空间，避免整张手机画布被放大。旅行规划在桌面分成目的地与行囊两栏，窄屏竖排。
- 长按钮支持换行；中英双语在 320、360、768、1440 像素宽度下检查。领养输入框占位文案随语言变化，切换物种保留自定义昵称。
- 陪伴、旅行和钱包页提供统一的伙伴选择器；照顾或钱包操作进行时禁止换伙伴。
- 旅行目的地、收藏或当前旅行读取失败时显示重试入口，不再把失败当作已加载。未知旅行状态不会显示可出发的规划表。
- 读取开始时固定伙伴身份；请求途中换伙伴会排队读取新伙伴的旅行。切换档案会取消旧请求的写入资格，旧响应不能覆盖新档案。
- 钱包页检查旅行状态；状态未知、读取中或失败时不能赠送。
- 补齐 npm 锁文件缺失的可选依赖，恢复 `npm ci --ignore-scripts`。
- 新增 Node 图鉴生成器，Godot 构建与测试自动生成 120 项设计图鉴（仅 3 位已开放）。无需额外安装 Python。
- 新增跨平台 `npm run test:godot`，测试失败会返回非零退出码。截图工具要求测试模式，不会建立玩家会话。

## 从源码查看本轮效果

在项目根目录使用 Node 24 和 Godot 4.5.2：

```powershell
npm ci --ignore-scripts
npm run build:codex
node server/src/index.ts
```

保持 API 运行，在另一个终端启动客户端：

```powershell
Godot_v4.5.2-stable_win64_console.exe --path game
```

本机 API 默认使用 `runtime/pets.sqlite`，重新启动会保留存档。网页版本需要匹配的 Godot Web 模板，然后执行 `tools/build.ps1 -Target Web` 与 `tools/start.ps1`。

运行客户端回归：

```powershell
$env:PIXELPETS_GODOT_PATH = 'D:\Godot_v4.5.2-stable_win64_console.exe' # 替换为本机路径
npm run test:godot
```
