# PixelPets 可玩版本交付与验证

本轮完成免费游戏的完整游玩流程，并生成实际 Web 与 Windows 导出。通过一键启动便携包，在本机运行养成服务和浏览器游戏；包内自带 Node.js 24，不依赖 npm 安装或 Godot 编辑器。

## 游戏体验

- 3 种伙伴、日光 / 月色两条成长分支；小屋、集市和月灯小径使用原创程序化像素场景。
- 六束微光互动小游戏，支持鼠标、触屏与键盘，完成后只向服务器提交一次照顾记录。
- 照顾冷却倒计时由服务器时间计算，使用单调时钟更新；到期自动恢复按钮。
- 6 点亲密成长后的庆祝画面、日光 / 月色印记、轻柔合成音效与静音开关。
- 8 件纪念物各有像素插画；相册可重读最近 50 次旅行中的已揭晓明信片，刷新页面后仍可加载。
- 结果概率、可选链上收据放在可展开区域；核心奖励揭晓与后续游玩按钮更清楚。
- 新玩家引导、游戏内玩法指南、双语日记。新增日记翻译表为增量迁移，旧记录保持原文。
- 桌面和窄屏布局；弹窗打开时改变窗口尺寸也会更新边距。

## 构建与复现

```powershell
npm ci --ignore-scripts
npm test
npm run typecheck:server
npm run typecheck:sdk
npm run typecheck:wallet
$env:PIXELPETS_GODOT_PATH = '你的 Godot 4.5.2 可执行文件路径'
npm run test:godot
./tools/build.ps1 -Target All
npm run package:release
npm run test:release
```

`package:release` 面向 Windows x64：需要先完成导出，将 Node.js 对应版本的官方完整 LICENSE 保存为 `runtime/node-LICENSE.txt`，Godot LICENSE 保存为 `runtime/Godot-LICENSE.txt`。默认输出 `dist/release/PixelPets`；也可给脚本传入新的绝对输出目录。只复制游戏、运行时、编译后的服务、启动器与许可，不复制开发数据库、钱包密钥或环境变量文件。打包目录应为新建空目录。

Godot 4.5.2 导出模板来自官方发布，提取的模板进行了 ZIP CRC 与引擎版本校验。沙箱内 Godot 的原子文件替换受限；存档测试与正式导出在本机工作区运行，未通过关闭安全保存规避错误。构建错误会使脚本失败。
